# Security policy

## Supported version

Only the latest commit on `main` is supported.

## Reporting a vulnerability

Do not open a public issue containing credentials, private conversation data, or exploit details. Use GitHub's private vulnerability reporting for this repository when available.

Include the affected component, reproduction steps, expected impact, and any suggested mitigation. Remove API keys, tokens, personal data, and provider response content from screenshots or logs.

## Deployment warning

The current backend is designed for private, single-user access over loopback or a trusted tunnel. It is not approved for an unauthenticated public deployment. See `RUNBOOK.md` for the required controls before expanding access.
